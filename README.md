# Solpor de Arousa

Landing page for **Solpor de Arousa**, a rural house (casa rural) in Bamio, Vilagarcía de Arousa (Pontevedra, Galicia).

Built with [Astro](https://astro.build/). Multilingual: Spanish (default), English and Galician.

## Property

- **Address:** Rúa Pedroso, 46, 36618 Bamio, Pontevedra
- **Capacity:** up to 8 guests
- **Rental:** whole house only
- **Contact / WhatsApp:** +34 620 06 76 10
- Features: 3 bedrooms, 2 bathrooms, private pool, stone barbecue, sea views, parking.

## Project structure

```
src/assets/images/    Photos — processed by astro:assets (WebP + srcset at build time)
src/i18n/content.ts   All translations, contact data, gallery list + alt text, FAQ
src/layouts/          Base layout (SEO, hreflang, OG, JSON-LD)
src/components/       Header, Hero, House, Amenities, Gallery, Nearby, Faq, Book, Footer, Page
src/pages/            index (ES), en/index, gl/index, 404
src/styles/global.css @font-face + design system + styles
public/fonts/         Self-hosted Fraunces + Source Sans 3 (latin, latin-ext)
public/robots.txt     Points at /sitemap-index.xml
public/_headers       Netlify long-cache headers for /_astro/* and /fonts/*
```

Photos live in `src/assets/images/`, **not** `public/`: that is what lets Astro emit
WebP derivatives with `srcset` and intrinsic `width`/`height`. Adding a photo means
importing it in `src/i18n/content.ts` with alt text for the three locales.

Fonts are self-hosted rather than loaded from `fonts.googleapis.com`, to avoid a
render-blocking cross-origin request. To update a font, replace the `.woff2` under
`public/fonts/` **and** the matching `@font-face` block at the top of `global.css`
(rename the file so the immutable cache header in `_headers` does not serve a stale copy).

## SEO notes

- `sitemap-index.xml` is generated by `@astrojs/sitemap` with `xhtml:link` hreflang
  alternates; `robots.txt` points at it. Submit it in Google Search Console.
- The homepage emits a JSON-LD `@graph` with `LodgingBusiness` + `FAQPage`.
  FAQ copy lives in `content.ts` and feeds both the visible accordion and the schema —
  edit it in one place only.
- Every FAQ answer must stay factually true of the property; the schema repeats it to Google.

## Deploy

Static output; deploy `dist/` to Netlify, Vercel or Cloudflare Pages. Point the domain
`solpordearousa.com` at it. `public/_headers` is Netlify-specific — on Cloudflare Pages
it works as-is, on Vercel it needs translating to `vercel.json`.
